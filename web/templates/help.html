📖 Hướng dẫn sử dụng Sakura Bot

Từ mời bot đến cấu hình server — tất cả chỉ trong 3 bước

1

🤖 Mời bot vào server

Nhấn nút Mời Sakura, chọn server, cấp quyền Quản trị viên. Bot sẽ tự online và sẵn sàng nhận lệnh s!help.

2

🔐 Đăng nhập Dashboard

Vào /login → Đăng nhập bằng Discord. Hệ thống tự động lọc chỉ hiện server bạn có quyền Quản lý Server. User thường chỉ thấy server của mình, admin thấy toàn bộ.

Đăng nhập
3

⚙️ Cấu hình server

Vào /dashboard → chọn server → chỉnh Prefix, Ngôn ngữ, Welcome, AutoMod, Logs. Nhấn Lưu là áp dụng ngay lập tức.

❓ Câu hỏi thường gặp (FAQ)

Tại sao không thấy server của mình?

Bạn cần có quyền Quản lý Server trong Discord và bot đã được mời vào server đó. Thử đăng xuất và đăng nhập lại bằng Discord.

Làm thế nào để xem toàn bộ danh sách lệnh?

Bạn có thể gõ s!help trong kênh chat Discord hoặc truy cập mục Lệnh Bot trực tiếp trong Bảng Điều Khiển.

Phân quyền Quản trị & Owner hoạt động ra sao?

Khi đăng nhập qua Discord, tài khoản Owner (@linhxinh_dev) sẽ tự động nhận toàn quyền quản trị cao nhất và quản lý mọi server mà bot tham gia.
